# جعبه لایتنر اسپانیایی به فارسی (PWA)

## فایل‌ها

- `index.html`: کل برنامه (ظاهر، منطق لایتنر، ذخیره‌سازی)
- `sw.js`: Service Worker برای اجرای آفلاین
- `manifest.webmanifest`: مشخصات نصب (نام، آیکن، حالت تمام‌صفحه)
- `icons/`: آیکن‌ها

## انتشار روی GitHub Pages (از کامپیوتر یا خود آیفون)

1. در github.com یک ریپازیتوری **Public** بسازید، مثلاً با نام `leitner`.
2. **Add file ← Upload files** را بزنید و همه فایل‌ها و پوشه `icons` را آپلود کنید. ساختار باید دقیقاً همین باشد و `index.html` در ریشه ریپازیتوری قرار بگیرد.
3. به **Settings ← Pages** بروید. در بخش Source گزینه **Deploy from a branch** و بعد شاخه `main` و پوشه `/ (root)` را انتخاب کنید و Save بزنید.
4. یکی دو دقیقه صبر کنید تا آدرس ساخته شود: `https://USERNAME.github.io/leitner/`

## نصب روی آیفون

1. آدرس را **در Safari** باز کنید. مرورگرهای دیگر برای نصب روی آیفون مناسب نیستند.
2. دکمه **Share** را بزنید و **Add to Home Screen** را انتخاب کنید. اگر گزینه **Open as Web App** دیده می‌شود، روشن باشد.
3. از این به بعد برنامه را فقط از آیکن صفحه اصلی باز کنید. حافظه اپ نصب‌شده از حافظه Safari جداست.

## یادآوری روزانه (اختیاری)

در اپ **Shortcuts** به بخش Automation بروید و **Time of Day** را انتخاب کنید. ساعت دلخواه را تنظیم کنید و برای اکشن، **Open URL** را با آدرس برنامه بگذارید. گزینه Run Immediately را هم روشن کنید.

## به‌روزرسانی برنامه

بعد از تغییر هر فایل، در `sw.js` مقدار `VERSION` را بالا ببرید (مثلاً `leitner-v1.0.1`). دفعه بعد که برنامه با اینترنت باز شود، نسخه جدید گرفته می‌شود. **داده‌های شما حفظ می‌شوند**، چون در localStorage هستند و نه در کش.

## نکات حافظه

- داده‌ها به آدرس سایت وابسته‌اند. اگر آدرس یا نام ریپازیتوری را عوض کنید، داده‌ها در آدرس جدید دیده نمی‌شوند. قبل از این کار از بخش تنظیمات پشتیبان بگیرید.
- هر چند هفته یک بار از تنظیمات، **ذخیره پشتیبان** را بزنید و فایل را در iCloud Drive نگه دارید.
- برای افزودن لغت به‌صورت گروهی، هر خط را به این شکل بنویسید: `la playa ; ساحل ; مثال اختیاری`
